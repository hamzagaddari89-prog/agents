# Friction / Learning Promotion Log

Capture recurring friction or discoveries from real sessions that should
eventually become a rule, skill, agent definition, or documentation.

Promotion is **human-controlled**: nothing in this layer reads, parses, or
automatically applies anything from this file. It is a notebook, not a system.

## How to use

1. When a session hits friction (repeated fix, surprising behavior, a rule
   that should have existed), append a Candidate below. Be specific.
2. When the same friction appears a second time, promote it: write the actual
   rule/skill/agent/doc, then set Status: promoted with the destination.
3. If an idea is not worth it, set Status: rejected with one line why.
   Rejected candidates stay visible — they prevent re-proposing the same thing.

## Template

```markdown
## Candidate: <short title>

- Date: <YYYY-MM-DD>
- Project: <project name or "general">
- Problem: <what went wrong / what friction occurred>
- Observation: <evidence — how often, where>
- Proposed improvement: <what to add/change>
- Destination: skill | rule | agent | docs
- Status: candidate | promoted | rejected
```
